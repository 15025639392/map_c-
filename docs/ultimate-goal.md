# 地球引擎终极目标（Ultimate Goal）与多路协调总纲

> 本文件是**整仓的"为什么"与"怎么协同"**：一句话终极目标 → 终局验收口径 →
> 里程碑/波次计划 → 多路并行协调规则。判据契约仍以
> `docs/northstar/*.md` 与 gis-md 冻结档案为权威；本文不新增判据，只钉目标与协同。
> 状态：2026-09-09（地形 host 机制闭环 + Android 上屏后；系统缺口见
> [system-gap-audit.md](system-gap-audit.md)）。

## 1. 一句话终极目标

> **做一台自研的、移动优先的 C++17 3D 地球引擎：真实地表内容（地形/影像/矢量）以
> 流式与预算化的方式上屏，任意机位任意加载阶段都读得出地貌与内容、瓦界与换代不可见；
> 为此付出的每一字节下载、每一次烘焙、每一个三角形都有屏上消费——最终形态 = 可嵌入
> App 的 `earth_engine_core` + 各平台薄壳 demo（可交付、可演进、可换肤）。**

（由 gis-md 北极星四轴形态与本仓 engine-targets §0 提炼：体验轴"任意机位可读+换代
不可见"、调度效率轴"每字节有账有消费"、性能/资源轴为预算约束。）

## 2. 终局验收口径（怎么算"达成"）

| 轴 | 口径 |
|---|---|
| 能力 | 地形 + 影像 + 矢量三类内容同屏正确叠合（贴地、不浮空、换肤不刷、退化不空白） |
| 判据 | 各模块北极星判据表逐条 ✅——观感类经用户像素拍板（机位截图集为证据），机制类 host/真机自证 |
| 体验 | 五固定机位 + 交互（惯性/锚定/不穿地）在真机稳定可跑；换代/瓦界不可见有截图与机制双证 |
| 预算 | 性能/资源/调度轴有真机账：帧时、内存、下载/烘焙/三角形利用率可审计（T-E*/T-P* 族回填） |
| 形态 | `earth_engine_core` 静态库 + ≥1 平台 demo 可持续构建出帧；文档/证据/判据口径自洽 |

## 3. 里程碑路线（波次视角）

- **已完成**：坐标/瓦片/LOD 地基 → 地形 host 机制全闭环（44→ 套件、真实资产/网络源回归、
  A4 并入 host 收官）→ Android 模拟器出帧（assets + NASA 514 网络源五机位）。
- **L1（当前）**：资源-调度流水线第一步（字节缓存/预取）、影像语义先行（退化链状态机）、
  相机运动模型 host 化、内容注册与元数据地基——全部 host 先行、单模块并行。
- **L2**：渲染抽象（RenderDevice 接口 + host 空实现 + GLES3 实现）→ 影像同屏（观感判据 T-V*
  可测化）。GPU 高度纹理路径：编码核+模板核+等价对拍 host ✅（56 套件）、设备高度纹理
  frag 上屏 ✅（hgt 模式 distinct 130）；**顶点位移几何**：位移向量属性通道 ✅——基准椭球
  模板 + 逐瓦位移 attribute（aDisp，`p=aPos+aDisp`）模拟器上屏，几何与 baked 逐像素一致
  （截图 disp1/baked0_station2，Δpx≈0.003%，glErr=0）；共享模板高度纹理驱动位移（无逐瓦
  位移属性）仍受模拟器 GLES vertex 纹理采样限制 → 真机路线开放项。
- **L3（当前）**：影像真实源（高德卫星+注记，前段已落）→ **相机导航成熟化 slice A ✅**：
  引擎层相机制 **MapCameraSystem**（turret 语义；手势→速率→惯性→贴地防护→flyTo 目标贴地抬升；
  host 57 套件含 14 用例）落地 + demo 手势层接线（`debug.mapc.nav`=1：Java 只送屏幕增量，
  引擎每帧步进回灌；`debug.mapc.flyto` 触发飞行）。**slice B ✅**：中心平移（pan）——双指质心
  →ENU 地面投影米/秒（与旋转/缩放同阻尼/收敛/上限、同帧组合），贴地防护随中心走；demo 双指拖动
  =平移（捏合缩放保留、单指旋转/俯仰）。设备证据：惯性滑行/贴地 clamp（flyTo 10m→抬至
  ground+5=237m）/pan lon 106.440→106.404/nav=0 基线像素不变，截图 `docs/assets/nav1_*.png`。
  **线① ✅ 手势识别器抽象**：引擎 `interaction/PointerGestureRecognizer`（平台无关触摸流 →
  单指旋转/双指平移+捏合，7 用例；demo nav=1 改为纯转发原始触摸，识别在引擎 C++ 完成——
  设备回归 glide 正常；nav=0 基线不变）。剩余：LOD 感知控制 → 图层栈 S3 化 → 矢量贴地/样式。
- **L4**：光照/大气/颜色、时间动画接换代过渡、格式与 3D Tiles、交互系统化。
- **L5（远期）**：天气/环境；roadmap 7–10（绘制/测量、性能离线工程化、真机预算账）。

## 4. 多路协调规则（coordinator 负责制）

1. **谁干活**：独立任务 = 后台子代理（本会话）或分区窗口（docs/WORK-PARTITION.md）；
   每路一个自包含简报，只新增自己名下文件，**不构建共享目录、不 commit/不 push**。
2. **谁集成**：coordinator（主会话）串行做——注册 CMakeLists、构建修复、全量
   `./test_native.sh` 绿、固定机位基线不回退、文档/计数/判据证据统一、单 commit 推送。
3. **波次纪律**：每波 ≤3–4 路且目录互不重叠；一波集成全绿后再开下一波；
   共享资源（模拟器/真实网络/build 目录）串行使用。
4. **质量底线**：结论带证据；判据编号只增不改；观感归用户；
   文档口径以 coordinator 汇总为准（防多路各写各的）。
5. **失败处理**：子代理回报失败/阻塞 → coordinator 决定重派、降级或记录停点（不进死循环）。
